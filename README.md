Hach
Une description courte et efficace de ce que fait votre projet (ex: "Un outil léger pour générer et vérifier des empreintes numériques de fichiers").

 Fonctionnalités:
Multi-algorithmes : Support pour MD5, SHA-1, SHA-256, etc.

Rapidité : Optimisé pour le traitement de fichiers volumineux.

Interface simple : Utilisation intuitive via la ligne de commande (CLI).

Vérification : Compare automatiquement un fichier avec un hash donné.
